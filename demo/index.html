Demo věrně reprodukuje kontrakty jádra: create_listing, verify (cenový engine + refund + risk), idempotentní kredity, gating náhled/detail, FOC rate limit. Vše běží jen v prohlížeči.

Tržiště — veřejný náhled (listings_preview)

Mřížka čte náhled (marketing). Klik na „Plný detail" čte base listings — bez aktivního předplatného Inzerce vrátí 0 řádků → CTA „Aktivovat Inzerci".

Ověření protistrany

Cena = součet kreditů zapnutých rejstříků v úrovni. Placená úroveň → nejdřív rozpočet (quote), po potvrzení jeden strh; selhaný rejstřík se refunduje. FOC (zdarma) má denní limit. Tip: IČO 00000000 nebo jméno Selhani Test simuluje technické selhání.

Kredity & předplatné

Platby simulují Comgate → payment-callback. add_credits je idempotentní dle ID platby — „Zopakovat callback" připíše jen jednou.

Vložit inzerát — RPC create_listing

Tvorba jde výhradně přes create_listing. První inzerát v roce strhne 1 kredit a ověří totožnost; další v roce už ne; bez kreditu → no_credit.

Admin moderace

Inzeráty se zakládají jako pending. Admin je schválí (→ active, objeví se v tržišti a odejde e-mail) nebo zamítne. Vyžaduje zapnutou roli admin (vlevo).
